# License scope

The MIT `LICENSE` applies to the repository-authored manuscript, code, prose,
tests, metadata, and project-generated certificates:

| Paths | Scope |
| --- | --- |
| `paper/**` | original manuscript source and compiled paper |
| `scripts/**` | original assurance and validation code |
| `docs/**` | original claim, source, history, and reproducibility documentation |
| `evidence/**`, `results/**` | project-generated exact outputs and receipts |
| root Markdown, CFF, workflow, and manifest files | package documentation and metadata |

## Third-party boundary

The MIT grant does not apply to cited papers or to third-party mathematical
results. Those works are incorporated by citation only. The repository does
not redistribute third-party article PDFs, source archives, datasets, or
subscription-database content. See `docs/SOURCE_LOCK.md` for the exact role of
each cited source.
