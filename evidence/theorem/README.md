# Theorem Evidence Boundary

The reader-facing all-order proof is the LaTeX manuscript under `paper/`.
`evidence/finite_assurance/THEOREM_DERIVATION.md` preserves a detailed
standalone derivation used as an authenticated input by both finite-assurance
implementations.

Neither the derivation document nor the executable finite panel replaces the
proof printed in the paper.  The panel checks declared orders, exact
conventions, and falsification mutations only.
