# Theorem Evidence Boundary

The reader-facing all-order proof is the LaTeX manuscript under `paper/`.
`evidence/finite_assurance/THEOREM_DERIVATION.md` restates the q-ary argument
in a standalone audit format.

The executable finite panel is narrower: it checks the binary specialization
at six even orders. It does not implement the direct q-ary membership theorem
and does not replace any displayed proof.

The proof-level construction permits every injective antisymmetric real
weight map. The polynomial-bit membership statement is the separately typed
integer-weight specialization; the executable panel does not widen that
algorithmic domain.
